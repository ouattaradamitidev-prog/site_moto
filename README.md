# STEED – site de démonstration

Site vitrine statique (HTML, CSS, JavaScript) pour une marque de motos fictive,
intégré et personnalisé par **Damel Dev** ([damel.vercel.app](https://damel.vercel.app/)).

La structure de départ vient du tutoriel « Build a Cool Bike Website from Scratch »
de Web Design Mastery. Le contenu a été traduit en français et le site adapté
(accessibilité, contraste, images WebP, métadonnées, favicon).

## Lancer le site

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8000
```

## Dépendances (CDN, versions figées)

- Remix Icon 4.6.0
- Swiper 11.2.10
- Polices Roboto et Roboto Condensed (Google Fonts)

## Contenu fictif

Les chiffres de la section « À propos », les modèles et les services sont des
données de démonstration, sans valeur réelle.
